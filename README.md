
# Cynaris Week 1 Day 4 
## Responsive Design & Media Queries

## Objective
Build a responsive web page using mobile-first CSS.

## Tasks
- Created a mobile-first layout.
- Added tablet and desktop breakpoints.
- Used relative units such as rem and percentages.
- Tested the page at different viewport widths.

## Technologies
- HTML5
- CSS3
- Media Queries
- CSS Grid and Flexbox

## How to Run
Open index.html in a browser.
Use Chrome DevTools (F12) and Toggle Device Toolbar to test responsive layouts.
